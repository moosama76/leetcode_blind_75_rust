# Blind 75 — Rust 🦀

Rust solutions to the [Blind 75](https://leetcode.com/problem-list/oizxjoit/) problems.

> **Note:** LeetCode's Rust support can be awkward for pointer-heavy problems, especially linked lists and trees, due to their provided data structures and Rust's ownership model.

All solutions in this repo are written in **Rust**. For problems where LeetCode's Rust interface is impractical, the equivalent **C++ solution is used for LeetCode judging**, while the Rust implementation remains here as the primary solution.

Solutions aim to be **idiomatic Rust**, with time and space complexity noted where relevant.
